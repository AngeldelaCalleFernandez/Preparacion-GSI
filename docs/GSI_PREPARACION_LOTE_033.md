Matices comprobados:

- XSD tiene tipos y facetas más ricos que una DTD, que también tiene restricciones. Un esquema XSD usa representación XML; validar no demuestra toda verdad de negocio.
- Namespaces: identidad por URI y nombre local; prefijos locales, ámbito y alias. La URI no exige descargar un esquema y no codifica automáticamente una versión o el significado de negocio.
- Esquema e instancia son papeles en una evaluación concreta. El propio esquema puede ser XML y ser instancia en otro contexto sin confundir esas funciones.
- Cardinalidad cuenta ocurrencias de partículas: minOccurs/maxOccurs, predeterminado uno. No es faceta de valor, compositor o restricción de identidad; atributos usan use y no se trasladan ocurrencias a declaraciones globales.
- El microcaso edad contiene texto bien formado pero fuera del léxico entero del XSD sin targetNamespace. La misma cadena puede parsearse y no ser válida respecto al esquema.
- Versionado: práctica de contrato compartido, sin obligación de cambiar namespace en cada revisión. La discusión TAG consultada es borrador editorial de 2007 sin consenso; no se presenta como regla normativa.
- El receptor usa la versión contractual del esquema, no cualquier schemaLocation de la instancia: las ubicaciones son pistas. La validación no autoriza alterar el contrato para que pase el mensaje.
- XPath expresa navegación, selección y cálculo; XSLT construye resultados usando expresiones. Las versiones fijadas no se confunden: ejemplos XPath/XSLT 1.0 no prueban soporte íntegro de XPath 3.1 o XSLT posteriores.
- XHTML: nombre histórico de la sintaxis XML para HTML. El estándar actual la considera esencialmente sin mantenimiento y no la recomienda para autoría general. MIME y análisis importan; extensión o cierres /> no cambian por sí mismos el régimen.
- JSON admite un valor simple superior, no es JavaScript general ni HTTP. YAML admite estilos flow además de indentación; se conserva la comparación sin imponer una única forma YAML.
- La adecuación documental de XML no equivale a ventaja universal de rendimiento o seguridad. JSON también tiene esquemas y firma; las fuentes JSON Schema y JWS impiden atribuir exclusividad de esas capacidades a XML.
- JSON no preserva nativamente identidad/referencias arbitrarias de objetos y parsear no valida un contrato. stringify puede rechazar ciclos y el formato no contiene un mecanismo de namespaces XML.
- Script es un uso/entorno, no una categoría formal que prohíba compilación. Se distinguen JavaScript y Java con documentación propia de Mozilla, TC39 y Oracle; la edición de trabajo ECMAScript 2027 no se presenta como final.
