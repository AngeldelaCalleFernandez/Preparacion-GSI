# GSI A2 — Guía de preparación del primer ejercicio (TEST)

**Formato vigente de ingreso libre:** máximo 100 preguntas más hasta 5 de reserva, 90 minutos. Cada error descuenta un tercio del valor de un acierto y las preguntas en blanco no penalizan. El primer ejercicio se califica de 0 a 50 y exige al menos 25 puntos, con la puntuación directa mínima fijada por la CPS conforme a la convocatoria.

## 1. Cómo usar los 57 temas

El test no se prepara leyendo los manuales una sola vez. Para cada tema sigue este ciclo: comprensión → resumen de una página → preguntas → registro de errores → repaso espaciado. Los apartados “Claves de test” de los cuatro manuales contienen las distinciones que más fácilmente se convierten en distractores.

## 2. Estrategia durante el examen

**Primera pasada:** responde las preguntas claras y marca las dudosas. Evita consumir varios minutos en una sola pregunta. Como referencia, 90 minutos para 100 preguntas dejan una media de 54 segundos por pregunta, aunque las fáciles deben resolverse mucho más rápido para reservar tiempo.

**Segunda pasada:** trabaja las dudosas eliminando alternativas. Con penalización de 1/3, responder completamente al azar entre cuatro opciones tiene esperanza matemática neutra; si puedes descartar con seguridad al menos una alternativa, la decisión de responder mejora. Esto no sustituye el criterio personal si una pregunta está mal recordada o contiene una trampa normativa.

**Final:** comprueba numeración y hoja de respuestas, especialmente preguntas omitidas y reservas. No cambies una respuesta solo por intuición tardía: cambia cuando hayas identificado un motivo concreto.

## 3. Qué memorizar y qué comprender

| Tipo | Ejemplos | Método |
| --- | --- | --- |
| Dato cerrado | plazos, composición, capas, siglas, puertos, categorías | tarjetas y test |
| Comparación | TCP/UDP, VM/contenedor, OLTP/OLAP, ENS/ENI, backup/replicación | tabla de diferencias |
| Proceso | incidentes, pruebas, ciclo de vida, riesgos, procedimiento | secuencia y casos |
| Diseño | arquitectura, seguridad, HA, datos | supuestos y diagramas |

## 4. Cuaderno de errores

Registra cada fallo con cinco campos: tema, pregunta/concepto, respuesta elegida, regla correcta y causa del error. Clasifica la causa como “no sabía”, “confundí conceptos”, “dato desactualizado”, “leí mal” o “arriesgué sin base”. El objetivo no es acumular preguntas, sino reducir errores repetidos.

## 5. Ritmo de entrenamiento

Durante aprendizaje: test cortos por tema. Tras completar un subbloque: test mixtos. Después de cada bloque: simulacro con tiempo. En fase final: exámenes completos y repasos dirigidos por error. Los test históricos deben usarse para aprender patrones, pero cualquier pregunta normativa o tecnológica antigua debe validarse con el temario actualizado.

## 6. Prioridades

Alta rentabilidad: administración electrónica/ENS/ENI, protección de datos, sistemas operativos, bases de datos, redes/TCP-IP, seguridad, desarrollo web, pruebas, ciclo de vida, arquitectura, almacenamiento/backup y conceptos actuales de contenedores. No descuides Bloque I: suele contener preguntas cerradas que permiten asegurar puntos con memorización precisa.
